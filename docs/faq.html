About Research

关于研究本身

这份报告的调研对象是谁？

调研对象是 2025 年沈阳举办的第二十三届中国国际装备制造业博览会（简称中国制博会，CIEME）。这是装备制造业领域的国家级大型经贸展览活动，已连续举办二十三届。

团队真的去过现场吗？

本作品基于公开资料整理与调研判断构建。问卷、访谈、现场观察的工具已经设计完成（见附录 A/B/C），但正式赴展调研需要配合下届展会现场开展。这一点在 数据透明度 页明确标注。

下一阶段团队将完成 N≥300 的问卷回收 + 24 场展商访谈 + 4 天现场观察，把待回填数据替换为真实数据。

报告里的数字都是真实的吗？

分情况：

  • 9 万㎡ / 912 家 / 3056 个 / 15.8 亿等核心规模数据来自展会官方与媒体公开报道（数据等级 A）
  • 展区构成、问题优先级、影响×可行性矩阵等是基于公开资料的团队推算与判断（等级 D）
  • 满意度问卷回填、KPI 仪表盘当前值是待回填数据（等级 E），明确标注"待问卷调研后回填"

详见 数据透明度 页对 20 张图表的逐项说明。

为什么选择中国制博会做调研？

三个原因：

  • 项目本身有价值：国家级专业展会，二十三届持续办展，规模与产业基础扎实
  • 研究意义足：四股力量（会展业 + 制造业 + 东北振兴 + 沈阳制造业基地）在一个项目上交汇
  • 调研可行性高：地理临近、公开资料丰富、有持续追踪空间

本作品最具创新性的点是什么？

四个层面：

  • 提出"北方智能制造产业链服务平台"定位，把会展项目从"展示场所"重新定义为"产业服务平台"
  • 建立可执行的产品蓝图，把建议方案拆成 18 项可发布功能，分三届展会逐步上线
  • 采用六阶段调研方法论，定量与定性方法交叉验证
  • 双载体作品体系：Word 报告 + 在线网站 + 合订本 + PDF + A1 海报，相互补充
About Content

关于报告内容

"九大问题"是怎么识别出来的？

从会展业一般规律 + 中国制博会公开资料 + 标杆展会对比三个角度归纳：

  • 会展业研究文献里反复出现的关键议题（专业观众、数字化、展后转化）
  • 中国制博会公开报道中可观察的现象（展区设置、活动安排、宣传渠道）
  • 与 CIIF / CIMT / CHTF / HMI / EMO 五大标杆对比的能力差距

每个问题都按"影响程度 × 改进紧迫性"双维度评估优先级，结果见图 F5。

"11 项建议"和"九大问题"如何对应？

9 类问题映射到 11 项建议，每条问题至少有一条建议覆盖，形成闭环。映射关系见图 F6（问题—建议桑基图）。

其中三类高优先级问题（专业观众组织、数字化服务闭环、展后转化机制）对应四项核心工程建议，是项目从规模型走向平台型的关键切入点。

报告对沈阳和东北有什么意义？

展会即是城市。中国制博会的升级与城市的产业升级、东北的振兴战略本质上是同向同行：

  • 对城市：通过展示先进制造、智能装备、机器人、工业互联网等内容，更新外界对沈阳的产业形象认知
  • 对东北：作为东北最大装备制造类专业展会，是连接产业资源、招商资源和品牌资源的重要平台
  • 对国家：作为国家级展会，承担促进装备制造业高质量发展、产业链供应链协同的政策功能

建议方案是否可执行？

每项建议都包含核心思路 + 执行清单。我们专门做了一份 产品蓝图 页，把 11 项建议拆成 18 项可发布功能，分 v1.0 / v2.0 / v3.0 三届展会逐步上线，避免一次性堆功能造成现场失败。

同时提供五阶段实施甘特图（图 F9）、组织保障方案、风险控制清单。

Website

关于这个网站

为什么不做成移动 App？

三个原因：

  • 评委、主办方等用户分散，下载 App 门槛高
  • 网站本身已支持 PWA，可"添加到主屏"实现 App 体验
  • 专门为手机设计了 现场扫码版，无需安装

网站可以离线访问吗？

可以。网站采用 PWA 技术，配置了 Service Worker 离线缓存。首次访问后，后续访问可在无网络环境下查看所有页面与图表（除了在线 PDF 嵌入需要网络）。

网站怎么部署？

使用 GitHub Pages + GitHub Actions。每次 push 到 main 分支会自动触发部署，1-2 分钟后访问最新版本。访问地址：2711944586.github.io/hz。

页面看起来错乱了怎么办？

可能是浏览器缓存了旧版。解决方案：

  • 强制刷新：Ctrl + Shift + R （Windows）/ Cmd + Shift + R （Mac）
  • 清除 Service Worker：F12 打开开发者工具 → Application → Service Workers → Unregister
  • 无痕模式打开
