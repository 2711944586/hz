Data Scope

公开数据、衍生计算
与研究评价分层呈现

本页用于说明报告的数据使用方式。基础规模采用公开数据，运营效率采用公开数据衍生计算，问题诊断与建议采用研究评价，满意度和 KPI 等尚待现场回收的数据明确标注为示例。

Principles

四类数据边界

公开版报告强调可读性，也保留数据边界，避免把不同性质的信息混在一起。

公开数据

来自官方、政府主管部门、主流媒体或展会公开资料，用于呈现基础事实。

例：9 万㎡、912 家、3056 个展位

衍生计算

基于公开数据计算比例、密度、占比和效率，用于解释运营表现。

例：专业观众占比、平均展位配置

研究评价

基于公开资料、标杆对比和会展业规律形成团队判断，用于问题诊断和建议排序。

例：影响 - 紧迫性、影响 - 可行性

示例数据

用于展示图表形式和回填逻辑，正式赴展调研后替换为真实问卷或访谈结果。

例：满意度模拟、KPI 当前值

How To Read

数据使用方式

同一份报告里，"事实、效率、判断、示例"承担不同功能。混用会让结论变得不清楚，因此本页把它们拆开。

Read 01

看规模

展览面积、参展企业、展位数量、观众规模和成交金额用于判断展会基础能级。

Read 02

看效率

专业观众占比、平均展位配置、开幕日成交占比等指标用于观察运营效率。

Read 03

看方向

问题诊断和优化建议以研究评价为基础，服务后续办展质量提升。

Read 04

看局限

示例数据不能作为事实引用，只用于说明问卷回收后图表如何呈现和回填。
