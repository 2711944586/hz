## 一、作品速览

本作品是面向"全国大学生文化旅游与会展竞赛"的参赛作品，研究对象是 **2025 年沈阳举办的第二十三届中国国际装备制造业博览会（中国制博会）**。作品同时呈现为：

- **Word 调研报告**：459 段、21 张表、20 张图，含三段主体 + 第四部分延伸分析 + 第五部分案例对照 + 七个附录
- **GitHub Pages 在线版**：19 个页面、20 张交互图表、深色模式、PWA 支持、可填写问卷
- **合订本 docx**：590 段、38 张表、37 张图，把调研报告与在线扩展整合为一份提交版
- **PDF 在线版**：2 份 PDF（约 60 页 / 75 页），可在线阅读、可下载、可打印
- **A1 答辩海报**：1200×1697 px，可一键导出 PDF
- **17 张二维码**：覆盖所有页面，海报、展板、胸卡场景一键复用
- **18 张定制占位图**：与作品视觉一致，便于后续替换为真实照片

## 五、网站特性

- 🎨 **视觉风格**：沈阳工业蓝（#1E40AF）+ 高亮橙（#F59E0B）配色体系，统一字体与卡片样式
- 🌓 **深色模式**：顶栏一键切换，自动持久化（localStorage）
- 🖨️ **打印样式**：所有页面适配 @media print，可直接导出 PDF
- 📱 **响应式**：移动端、平板、桌面三档断点
- ⬆️ **回顶按钮**：滚动 300px 后出现
- 📑 **页内 TOC**：长页右侧自动生成目录，滚动同步高亮
- 🔍 **SEO**：favicon + OG meta + sitemap.xml + robots.txt
- 📲 **PWA**：可安装到手机主屏，service worker 离线缓存
- 🏷️ **二维码**：17 张 H 级容错码，遮挡 30% 仍可识读
- 📝 **在线问卷**：附录 A 可现场填写，本地保存 + 导出 CSV

## 七、本地开发

### 依赖

- Node.js 16+
- Python 3.10+
- 本机 Chrome 或 Edge（用于无头渲染）
- Microsoft Word（用于 docx → PDF 转换）

### 安装

```bash
git clone https://github.com/2711944586/hz.git
cd hz
npm install
pip install python-docx docxcompose docx2pdf qrcode
```

### 一键全量产出

```bash
# 1. 重新生成 20 张图表
node scripts/export_charts.js

# 2. 生成 17 张二维码
node scripts/gen_qr.js

# 3. 生成 18 张占位图
node scripts/gen_photo_placeholders.js

# 4. 生成 PWA icon
node scripts/gen_icons.js

# 5. 重写 docx 附录与第四五部分
python scripts/update_docx.py

# 6. 生成合订本 docx
python scripts/build_combined.py

# 7. docx → PDF（需 Word）
python scripts/export_pdf.py
```

### 本地预览

```bash
python -m http.server 8765 --directory docs
# 浏览器访问 http://localhost:8765/
```
